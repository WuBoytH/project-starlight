# Project Starlight
A skyline plugin to visualize in-game data.

## Installation
Place the downloaded plugin into `atmosphere/contents/01006A800016E000/romfs/skyline/plugins/`.

## Features
- Visualizes the following data in-game. Visualizations are set to *Off* by default, and can be toggled using the button combo listed.
  - Hitboxes (Start + DPad Up)
  - Hurtboxes (Start + DPad Left)
  - Environmental Collision Boxes (Start + DPad Right)
  - Ledge Grab Boxes (Start + DPad Down)
  - Level Data (Start + R)
